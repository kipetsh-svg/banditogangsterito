Bandito game project
 
## Правило интерфейса размещения карт

При выборе карты всегда одновременно показывать допустимые позиции для всех четырёх ориентаций: 0°, 90°, 180° и 270°. Для каждой ориентации использовать отдельный цвет маркера и давать возможность сразу поставить карту нажатием на соответствующий маркер. Не заменять это последовательным переключением ориентаций и не возвращать отдельную кнопку поворота.
