# banditogangsterito
Bandito game project
 
## Правило интерфейса размещения карт

При выборе карты всегда одновременно показывать допустимые позиции для всех четырёх ориентаций: 0°, 90°, 180° и 270°. Для каждой ориентации использовать отдельный цвет маркера и давать возможность сразу поставить карту нажатием на соответствующий маркер. Не заменять это последовательным переключением ориентаций и не возвращать отдельную кнопку поворота.
 
## Правило анимации новой карты

И в одиночном, и в кооперативном режиме анимация появления новой карты проигрывается ровно один раз при её размещении. Повторная отрисовка поля (выбор другой карты, просмотр поворотов, обновление интерфейса) не должна перезапускать анимацию. В одиночном режиме обводки последней карты нет. В кооперативе допускается тонкая сплошная обводка последней поставленной карты, почти вплотную к краю; спокойный серо-голубой цвет, без тени и второй рамки.

## Правило сброса карт и таймера хода

Сброс карт из руки под низ колоды разрешён исключительно в ситуации, когда ни одну карту из руки невозможно выложить на поле ни в одной из четырёх ориентаций. Истечение таймера хода в кооперативе (60 секунд) приводит только к пропуску хода (очередь переходит к следующему игроку), карты в руке сохраняются.



## Структура проекта

- `index.html` — разметка экранов и подключение ресурсов.
- `css/` — стили, разделённые по назначению. Порядок подключений в HTML важен: последние файлы содержат точечные переопределения ранних.
- `js/settings.js` — настройки, сохранение предпочтений и переключение темы.
- `js/game.js` — одиночная игра, правила, поле, управление и экран результата.
- `js/multiplayer.js` — Firebase, комнаты, список игроков и кооперативная партия.
- `assets/images/` — логотипы, фоны и декоративные изображения.
- `resources/bandido-matrices/` — данные игровых карт.

### Как это работает

Это остаётся обычным статическим сайтом для GitHub Pages: без сборщика, npm и дополнительных команд. Скрипты подключаются в порядке `settings.js` → `game.js` → `multiplayer.js`; Firebase загружается перед ними. Все экраны остаются в одном `index.html`, потому что меню, игровое поле и комната ожидания переключаются внутри одного приложения.

### Где что менять

- Внешний вид и цвета — файлы в `css/`.
- Логику одиночной игры — `js/game.js`.
- Комнаты и сетевую игру — `js/multiplayer.js`.
- Настройки и переключение дня/ночи — `js/settings.js`.
- Состав колоды — `resources/bandido-matrices/cards.json`.
