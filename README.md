# banditogangsterito
Bandito game project
 
## Правило интерфейса размещения карт

При выборе карты всегда одновременно показывать допустимые позиции для всех четырёх ориентаций: 0°, 90°, 180° и 270°. Для каждой ориентации использовать отдельный цвет маркера и давать возможность сразу поставить карту нажатием на соответствующий маркер. Не заменять это последовательным переключением ориентаций и не возвращать отдельную кнопку поворота.
 
## Правило анимации новой карты

И в одиночном, и в кооперативном режиме анимация появления новой карты проигрывается ровно один раз при её размещении. Повторная отрисовка поля (выбор другой карты, просмотр поворотов, обновление интерфейса) не должна перезапускать анимацию. В одиночном режиме обводки последней карты нет. В кооперативе допускается тонкая сплошная обводка последней поставленной карты, почти вплотную к краю; спокойный серо-голубой цвет, без тени и второй рамки.
